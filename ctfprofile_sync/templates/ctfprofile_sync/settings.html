Actions

Test Connection — Sends an empty payload to verify your URL and API key are correct.

Full Sync — Pushes all current CTFd data (challenges, users, teams, solves, and standings) to CTFProfile in one request. Use this after initial setup or to recover from a missed real-time event.

Quick Setup
  1. On CTFProfile, navigate to your event and open Integrations.
  2. Copy the Event API Key and the Event Slug from the integrations page.
  3. Paste them into the fields on the left and save.
  4. Click Test Connection to verify everything works.
  5. Toggle Sync on solve to enable live updates, then click Full Sync Now to push existing data.
How it works

This plugin listens for new solves using SQLAlchemy's after_insert hook. When a flag is captured it POSTs a JSON payload to your CTFProfile instance.

CTFProfile matches users by CTFd username or a linked CTFProfile account. Teams are matched by name. Challenges are upserted by their CTFd ID.

The API key is specific to the event and is generated on the CTFProfile integrations page. Keep it secret — anyone with the key can write data to your event.
